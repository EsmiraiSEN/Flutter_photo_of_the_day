- setState и три состояния экрана (загрузка / ошибка / данные)

## Ответы на вопросы

1. **Что такое Future<T>? Чем отличается от обычного возвращаемого значения?**
   `Future<T>` — объект, который обещает вернуть значение типа `T` в будущем.
   Обычное значение доступно сразу, а `Future` — только после завершения
   асинхронной операции (через `await` или `.then()`).

2. **Что делает await? Блокирует ли он весь поток выполнения?**
   `await` приостанавливает **только текущую функцию** до завершения Future.
   Остальная программа (в т.ч. UI) продолжает работать — поток не блокируется.

3. **Зачем setState() вызывается дважды в _fetchPhoto()?**
   Первый раз — чтобы сразу показать индикатор загрузки и сбросить предыдущий
   результат. Второй — чтобы скрыть индикатор и отобразить результат/ошибку
   после завершения асинхронной операции.

4. **Почему кнопке передаётся _fetchPhoto без скобок, а не _fetchPhoto()?**
   Без скобок передаётся **ссылка на функцию** (callback), которую Flutter
   вызовет при нажатии. С `_fetchPhoto()` функция выполнилась бы сразу при
   построении виджета.

5. **Чем Image.network() отличается от Image.asset()?**
   `Image.network()` загружает картинку по URL из сети.
   `Image.asset()` берёт картинку из локальных ассетов проекта
   (папка `assets/images/`, объявленная в `pubspec.yaml`).
